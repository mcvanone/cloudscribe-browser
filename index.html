Из видео — в удобный текст

Выберите видео или аудиозапись. Звук извлекается и распознаётся непосредственно в браузере на этом MacBook. Исходные файлы не отправляются на сервер приложения.

Новое задание

▤ Перетащите файл сюда или нажмите, чтобы выбрать MP4, MOV, MKV, MP3, WAV, WebM
В этой версии поддерживаются файлы с компьютера. Ссылки Google Drive, Mail.ru и Dropbox из оригинальной программы пока не перенесены.
WebGPU в браузере отличается от MLX Whisper в приложении для macOS. При первом запуске модель скачивается из Hugging Face.

Конфиденциальность

Файл читается через браузерные API и не загружается на наш сервер. Страница и файлы модели загружаются с внешних ресурсов (GitHub Pages, CDN, Hugging Face). Используйте рабочие видеозаписи только при наличии соответствующего разрешения компании.

Пока нет входа по корпоративной учётной записи, постоянной истории, облачных ссылок и экспорта DOCX.
